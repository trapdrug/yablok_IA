# README-ЗАПУСК (Frontend)

## Требования
- Node 20+ (`node -v`). Установка: `winget install OpenJS.NodeJS.LTS`
- Бэкенд Устройства 1 на порту 8000 (иначе фронт уйдёт в ДЕМО-МОК из `public/seed-03.json`).

## Запуск
```
cd frontend
npm i
npm run dev
```
Откройте http://localhost:5173

## Сборка
```
npm run build
npm run preview
```

## Стыковка с бэкендом
- `frontend/.env`: `VITE_API_URL=http://localhost:8000`
- Для LAN: замените на `http://<IP-бэкенда>:8000`, перезапустите `npm run dev`.
- CORS на бэкенде открыт (`*`), ничего дополнительно настраивать не нужно.
- Если API недоступен — сверху баннер «ДЕМО-МОК, API недоступен», цифры из `public/seed-03.json` (Air 18/6/12, Plus 8/5/3).

## Что проверять (acceptance)
- Без бэкенда: Air 18/6/12, Plus 8/5/3, 6 активных.
- С бэкендом: те же цифры с API; резерв/отгрузка/получение работают, 400 показывают hint.
- Сценарий IN-AIR-01 → 05.11 10:00: ORD-003/005 в угрозе, после перезагрузки цифры прежние.
- Производство: «8 Plus» → невозможно, CO2 2/8, +8 только 04.11; Gantt с переносами за 17:00.
- ИИ-чат: 4 чипа-вопроса, блок «на каких данных основан», ответы меняются после мутаций.
- Кнопки «Сброс к простому/расширенному» (расширенный: 36/8/28 и 20/8/12).
